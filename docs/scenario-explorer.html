          Concept labs

          Three ideas worth seeing in slow motion

          Which partition does a key go to?

          Kafka's default partitioner hashes the key with murmur2. Same key, same partition, every time. Ordering is guaranteed only inside one partition.

          Try ACC-1 three times, then ACC-2. Each lane keeps its own offsets.

          Blocking vs non-blocking retries

          Record #3 fails twice before it succeeds. Watch what happens to the records queued behind it.

          Blocking · transaction-processor

          Retry topics · notification-service

          Blocking keeps per-account order, which a ledger needs. Retry topics keep the partition moving, which suits SMS alerts where order matters less.

          What exactly-once really prevents

          The processor reads a payment, writes the validated record, then crashes before committing its offset. On restart it reads the same payment again.
